# Dox 脚本语法（.dox）

`sc` 命令的脚本解释器。当前是 v1：只有变量、输出、条件与少量控制指令，
没有循环、函数、命令返回值捕获（见文末“暂不支持”）。

## 运行

```bash
sc demo.dox          # 执行脚本（可省略 .dox 扩展名）
sc -n demo.dox       # 只做语法检查，不执行
sc -t demo.dox       # 跟踪执行，逐行打印实际运行的语句
sc -c "@echo hi"     # 直接执行内联代码（可省略 #!dox，代码里的 \n 会转换成换行）
```

- **先整体解析，后执行**：语法错误在执行任何一行之前就会报出来，不会跑一半才崩。
- 退出码：正常结束为 0，`@exit N` 为 N，出错为 1。

## 文件结构

```
#!dox
# 注释
<命令行>
@<指令> ...
```

1. 首行（跳过空行）必须是 `#!dox`，否则整个文件不算 Dox 脚本。
2. `#` 注释：整行注释，或“前面是空白”的行内注释（`a#b` 不算注释，同 bash）。
3. 不以 `@` 开头的行都是**普通命令行**，原样交给 Dox 的命令分发器，
   因此 `ls`、`cat`、`cd`、`img`、`cmd`、`&` 等用法与交互模式完全一致。

## 变量

```
@set name = "Dox 脚本"
@set dir = /tmp
@echo "路径是 $dir"
@echo "也可以写成 ${dir}/a.txt"
@unset name
```

- 定义：`@set NAME = VALUE`；删除：`@unset NAME [NAME ...]`。
- 引用：`$NAME` 或 `${NAME}`；`$$` 表示字面 `$`。
- **单引号内不展开**，双引号内展开：
  ```
  @echo '$name'    →  $name
  @echo "$name"    →  Dox 脚本
  ```
- 命令行转发时**引号会被去掉**（Dox 命令接收的是原始字符串，不是参数数组），
  所以 `cat "README.md"` 与 `cat README.md` 等价；引号只用于保护变量不展开。
  注意 Dox 的部分命令（如 `cat`）按空格切参数，带空格的路径本身就不受支持，
  这是命令层的限制，不是脚本语法的问题。
- 变量名不区分大小写，按大写下划线归一（`@set myName` 之后 `$MYNAME` 也能取到）。
- 取值顺序：**脚本变量 → Dox 变量体系（临时 > 永久 > 系统 config.json > 进程环境变量）→ 空串**。
  所以 `$CONFIG_LANG`、`$PATH` 这类 Dox 变量不定义也能直接用。
- 未定义变量展开为空串（同 shell），不做报错。

## 输出

```
@echo "hello"
@echo -n "不换行"
```

`@echo` 是**字面输出**：不做语言包替换、不做 `%` 格式化，所以 `@echo "100%"` 安全。

## 条件

```
@if $count > 1
@echo "大于 1"
@elif $count == 1
@echo "等于 1"
@else
@echo "其它"
@end
```

- 结构：`@if` … [`@elif` …] [`@else` …] `@end`，`@end` 必需且必须配对。
- 符号运算符：`==`、`!=`、`<`、`>`、`<=`、`>=`
  （两边都是数字时按数值比较，否则按字符串比较）。
- 单词运算符：`contains`、`startswith`、`endswith`。
- 真假判断：`@if $x` —— 展开后非空且不是 `0/false/no/off/n/null/none` 即为真。
- 取反：`@if not $x` 或 `@if ! $x`。
- 存在性：`@if defined NAME` / `@if undefined NAME`（NAME 按字面取，不展开 `$`）。
- 不支持 `&&` / `||`：用嵌套 `@if` 表达，语义更清楚。

## 控制指令

| 指令 | 说明 |
| --- | --- |
| `@exit [CODE]` | 立即结束脚本，退出码默认 0 |
| `@sleep SECONDS` | 延时，支持小数（`@sleep 0.5`） |
| `@source PATH` | 执行另一个 .dox 脚本，**共享变量表**；路径相对当前脚本所在目录 |

## 错误信息

错误统一输出为 `文件:行: 信息` + 源码行 + `^` 指示：

```
demo.dox:2: 未知脚本指令：@foo
    @foo
    ^
脚本执行结束，退出码 1
```

运行期限制：单次运行最多执行 100000 条语句（防死循环），`@source` 最多嵌套 8 层。

## 暂不支持（后续版本）

- 循环：`@for` / `@while`
- 函数与参数：`@func` / `@call`，脚本参数 `$1`、`$ARGV`
- 命令返回值捕获：`@set code = $(cmd)` 或 `$?`
- 表达式运算：算术、字符串拼接（目前只能靠 `$a$b` 直接相连）
- 数组/列表变量
